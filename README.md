Smart Task Manager App (a.k.a. “TaskZen”)
📱 Project Overview
A smart productivity/task manager app with features like:

Task creation with reminders, priority, category, and repeat logic

Voice input & speech-to-text (optional)

Local notifications and alarms

Offline-first with Room DB, syncs with Firebase (optional)

Dynamic theming (Material 3, light/dark/system themes)

Jetpack Compose UI with animations and navigation

Biometric lock for app security

DataStore for user settings

Adaptive layout (phone/tablet)
